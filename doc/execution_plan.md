3. **预处理脚本开发**：

## 第二阶段：Baseline模型实现（第4-6天）

### 目标
实现3个baseline模型，建立评估框架

### 具体任务
1. **MLP实现**：
   - [ ] 简单多层感知器（2-3层）
   - [ ] 支持不同输入维度
   - [ ] 超参数搜索（学习率、层大小）

2. **1D-CNN实现**：
   - [ ] 1D卷积网络（3-5层）
   - [ ] 不同卷积核大小（3,5,7）
   - [ ] 池化层和dropout

3. **ESN原型实现**：
   - [ ] ESN基础类（储备池、状态收集）
   - [ ] 岭回归输出层
   - [ ] 超参数配置接口

4. **评估框架**：
   - [ ] 统一训练循环
   - [ ] 准确率、F1-score计算
   - [ ] 结果可视化（混淆矩阵、学习曲线）

### 预期产出
- 3个baseline模型代码
- 统一训练脚本（train.py）
- 初步性能对比结果

## 第三阶段：第一轮实验（第7-9天）

### 目标
运行对比实验，评估ESN可行性

### 实验设计
1. **实验1：降维效果对比**
   - 输入：PCA降维至[10, 20, 30, 50]维
   - 模型：MLP, 1D-CNN, ESN
   - 指标：准确率、训练时间

2. **实验2：原始维度挑战**
   - 输入：原始高维光谱（降维前）
   - 模型：1D-CNN vs ESN（高维）
   - 指标：内存使用、训练稳定性

3. **实验3：输入组织方式**
   - 像素级 vs patch级（3×3, 5×5）
   - 模型：1D-CNN, ESN
   - 指标：准确率、计算效率

### 预期产出
- 实验报告（包含所有对比结果）
- ESN可行性初步结论
- 下一步优化方向

---

## 第四阶段：优化与深入（第10-14天）

### 目标

### 可能方向

3. **通用优化**：

   - [ ] 类别平衡处理
   - [ ] 集成学习

### 预期产出

- 最终性能报告
- 可发表的实验结果

## 风险与应对

### 风险1：数据获取延迟
- **应对**：优先使用ICVL（无需注册）
- **备选**：使用Indian Pines/Pavia University（经典但植物相关）

### 风险2：ESN效果不佳
- **应对**：提前准备1D-CNN作为主线
- **调整**：将ESN作为对照组，聚焦CNN优化

### 风险3：计算资源不足
- **应对**：使用降维数据减少计算量
- **优化**：使用小批量训练，梯度累积

### 风险4：过拟合严重
- **应对**：加强正则化（dropout, weight decay）
- **数据**：使用数据增强，交叉验证
